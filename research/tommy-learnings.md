# トミーさんのローンチページから「いいとこだけ」盗むメモ

作成日: 2026-11-22
もとにしたもの: https://utage-system.com/page/67Uv3ZzKH47U（「深夜3時の居酒屋で、数十億業者が口を滑らせた『3つの掟』」）
方針: 型（組み立て方）だけを学ぶ。言葉・煽り・数字の見せ方は真似しない。K は「50歳の余裕と自然体、争わない」

---

## 盗む（K に合う形に直して使う）

| トミーさんのやり方 | なぜ効くか | K での使い方 |
|---|---|---|
| 冒頭で「このレポートで明かす3つのこと」と**地図を先に渡す** | 先が見えると、最後まで読む | 無料note・LINE の連続配信の冒頭で「今回お話しするのは3つ」と先に示す |
| **3つに分けて、順番に明かす** | 1回で全部出さないので、次も読みたくなる | LINE の自動配信を「男の本音・3回シリーズ」にして、最後に鑑定書の案内 |
| 読む人の**「こころの声」を代弁**する | 「私のことだ」と思う | すでにやっている（「何か悪いこと言ったかな?」）。続ける |
| **読む人の疑問に先回り**する（「AIに聞けばいいのでは？」） | 迷いをその場で消す | 「占いって当たるの？」「男の人に私の気持ちがわかるの？」に先回りして答える |
| **自分の物語**を、具体的な数字や場面で語る（13歳で2,700円、など） | 本物っぽさと人柄が出る | 本当の話だけで（元スリランカ・インド料理の店、今はホテル暮らし、50になって考えが変わった）。盛らない |
| **やってほしいことを小さくする**（記入は4つだけ） | 手間が少ないと動く | LINE 登録や鑑定書の申し込みで聞くことを最小限に（今の案は3つ） |
| **感想や目標を書いてもらう** | 読む人が自分の気持ちを言葉にして、関わりが深まる | LINE 登録の特典の代わりに「彼にどうなってほしいか、一言」を送ってもらう、など |
| **P.S. で締める** | 本文で言い残した一番大事なことが、最後に残る | 無料note や LINE の長い文章の最後に、短い P.S. を1つ |

## 盗まない（K の空気感と合わない）

- 「断言します」「負け犬の遠吠え」など、強い言い切りや見下す言い方
- 期限のカウントダウンで急かす
- 大きな金額や「1億」を見せて欲を刺激する
- 「1年後の預金残高が変わります」のような、結果の約束
- 読む人の不安を突いて動かす

## 次に使う場面

- 公式LINE を作るときの、あいさつ〜連続配信の組み立て
- 無料note（`20261112_free-note-draft.md`）の書き直し（冒頭に「3つの話」の地図、最後に P.S.）
