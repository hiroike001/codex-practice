# codex-practice

これは、Codex と GitHub Desktop の使い方を練習するための小さなプロジェクトです。

## 入っているもの

- `index.html`：ブラウザで開ける練習用ページ
- `BEGINNER-GUIDE.md`：初心者向けの操作手順
- `README.md`：この説明ファイル

## まず何をすればいい？

1. GitHub Desktop を開きます。
2. `codex-practice` を選びます。
3. 上の `Fetch origin` を押します。
4. `Pull origin` が出たら押します。
5. `Show in Finder` を押して、中に `index.html` があるか確認します。
6. `index.html` をダブルクリックすると、ページがブラウザで開きます。

## 大事な考え方

GitHub Desktop の `No local changes` は「ファイルがない」という意味ではありません。

「前回保存した状態から、今は変更がない」という意味です。

ファイルの中身を見るときは、GitHub Desktop の `Show in Finder` を押します。

## Codex と GitHub Desktop の役割

- Codex：ファイルを作ったり、内容を直したりする係
- GitHub Desktop：変更を GitHub に送ったり、GitHub から取り込んだりする係
- GitHub：2台のPCで共有する保管場所
